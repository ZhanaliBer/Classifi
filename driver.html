Calculus describes how quantities change and how small pieces combine into a whole. These three topics build on one another: functions model relationships, limits explain behavior near a point, and derivatives measure instantaneous change.

Topics in this guide

  • Sets and Functions — domains, ranges, and ways to describe relationships between inputs and outputs.
  • Introduction to limits — what a function approaches, continuity, and the language of limits.
  • Derivatives — rates of change, tangent lines, and the first differentiation rules.

How the ideas connect

A derivative is defined using a limit. To understand derivatives, first get comfortable with functions and with the way function values behave as inputs approach a particular number.

Midterm Calculus · Topic 1

Sets and Functions

Big idea: A function assigns exactly one output to each allowed input.

Sets and intervals

A set is a collection of objects. In calculus, sets often describe possible real-number inputs. Interval notation gives a concise way to write ranges of real numbers:

  • [a, b] includes both endpoints: a ≤ x ≤ b.
  • (a, b) excludes both endpoints: a < x < b.
  • [a, b) includes a but excludes b.
  • (-∞, a] describes all real x less than or equal to a.

What is a function?

A function f from a domain D to a codomain assigns each input x in D one and only one output, written f(x). The domain is the set of allowed inputs; the range is the set of outputs the function actually produces.

f: D → R    x ↦ f(x)

For example, if f(x) = x² and the domain is all real numbers, then the range is [0, ∞). No real input produces a negative output.

Finding a domain

Start with all real numbers, then exclude inputs that make the expression undefined. In particular:

  • A denominator cannot equal zero.
  • The expression inside an even root must be nonnegative when working over the reals.
  • The argument of a logarithm must be positive.
Example: For f(x) = √(x − 2), require x − 2 ≥ 0. Its domain is [2, ∞).

Function notation and composition

The expression f(a) means evaluate the function at input a. If f(x) = 2x + 1, then f(3) = 7. Composition applies one function after another:

(f ∘ g)(x) = f(g(x))

Order matters: in general, f(g(x)) is not the same as g(f(x)).

Midterm Calculus · Topic 2

Introduction to limits

Big idea: A limit describes the value a function approaches as its input gets close to a point.

The meaning of a limit

We write the limit of f(x) as x approaches a as follows:

limx → a f(x) = L

This says that f(x) can be made as close as we like to L by taking x sufficiently close to a (but not necessarily equal to a). The function does not need to be defined at x = a for this limit to exist.

One-sided limits

A left-hand limit considers inputs less than a; a right-hand limit considers inputs greater than a. A two-sided limit exists precisely when both one-sided limits exist and agree:

limx → a⁻ f(x) = limx → a⁺ f(x) = L
Remember: If the left and right limits differ, the two-sided limit does not exist.

Limit laws

When the individual limits exist, limits respect familiar arithmetic operations:

  • Sum: lim(f + g) = lim f + lim g.
  • Product: lim(fg) = (lim f)(lim g).
  • Quotient: lim(f/g) = (lim f)/(lim g), provided lim g ≠ 0.
  • For a polynomial, direct substitution gives its limit at every real number.

If direct substitution gives 0/0, that is an indeterminate form—not the answer. Try factoring and simplifying, or use another algebraic method before evaluating the limit again.

Continuity

A function f is continuous at a when all three conditions hold:

  1. f(a) is defined.
  2. limx → a f(x) exists.
  3. limx → a f(x) = f(a).

Informally, the graph has no break, jump, or hole at that point.

Midterm Calculus · Topic 3

Derivatives

Big idea: The derivative gives the instantaneous rate at which a function changes.

Definition from a limit

The derivative of f at x is the limit of the average rate of change over a shrinking interval:

f′(x) = limh → 0 [f(x + h) − f(x)] / h

Geometrically, f′(a) is the slope of the tangent line to the graph at x = a. In an applied setting, it describes an instantaneous rate—for example, velocity is the derivative of position with respect to time.

Basic differentiation rules

  • Constant: d/dx(c) = 0.
  • Power rule: d/dx(xn) = nxn−1.
  • Constant multiple: d/dx[cf(x)] = cf′(x).
  • Sum: d/dx[f(x) + g(x)] = f′(x) + g′(x).
Example: If f(x) = 3x² − 4x + 5, then f′(x) = 6x − 4.

Product and quotient rules

For products and quotients, differentiate using the appropriate rule rather than differentiating each part separately:

(fg)′ = f′g + fg′     (f/g)′ = (f′g − fg′) / g²

Chain rule

For a composition of functions, differentiate the outer function and multiply by the derivative of the inner function:

d/dx f(g(x)) = f′(g(x)) · g′(x)

For example, if y = (3x + 1)², the chain rule gives y′ = 2(3x + 1) · 3 = 18x + 6.
